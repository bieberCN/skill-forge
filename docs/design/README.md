# Design Documentation

This directory is the living product-design record for Skill Forge. Every meaningful UI, contract, or workflow change should update one of these documents.

## Documents

- [`product-flow.md`](product-flow.md) — user journey and screen information architecture
- [`visual-system.md`](visual-system.md) — colors, spacing, typography, components, and responsive rules
- [`ADR-001-rfq-simulator.md`](ADR-001-rfq-simulator.md) — why the RFQ simulator is the first showcase product
- [`roadmap.md`](roadmap.md) — staged product and engineering improvements

## Update rule

For each design change, record the decision, the affected component, and the validation evidence. Do not treat screenshots as the source of truth; the contract and the design tokens are the source of truth.
